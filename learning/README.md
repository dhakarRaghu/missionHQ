# learning/

The daily learning journey's inputs and outputs, in the repo rather than the
vault — the vault has no remote, and it is the agents' memory layer, not
something the owner should have to read.

- `interests.md` — what he wants to read. The filter the morning scan applies
  before it judges whether a post is any good. **His file; edit it freely.**
- `sources.md` — the roster of people and publications, each with the date of
  the newest post someone actually opened. Also his to edit.
- `lessons/` — what tutor writes each morning: `<date>-<slug>.md` and the
  self-contained `.html` page the Learn view renders.

Agents read these through the learning pipeline. Nothing here is written by a
web-reading agent.
