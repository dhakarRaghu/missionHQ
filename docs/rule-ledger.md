# Rule ledger

Every rule, incident and quoted remark in today's prompts, and where it goes.
Nothing is deleted without a row here. You approve this file before any
prompt is edited. Line-level detail for each file is in
`docs/instruction-review.md` (tutor) and `docs/instruction-review-part2.md`
(everyone else); this file is the index you sign off.

Destinations: **charter** (`agents/_shared/charter.md`, every agent),
**card** (`agents/<name>/job.md`), **skill** (`agents/<name>/skills/*`),
**code** (a gate, tool constraint or pipeline step; "exists" means it is
already enforced), **data** (a yaml/md file read by code and briefs),
**test** (a regression case in `backend/evals/`), **incidents**
(`docs/incidents.md`, history for humans), **delete** (with the reason).
