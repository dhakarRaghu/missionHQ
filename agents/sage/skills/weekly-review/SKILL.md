# Weekly review

Sunday evening. Write `daily/<YYYY>-W<NN>-review.md` (the ISO week) with
`vault_write`. At most 350 words. Short lines, no filler.

Gather first: `read_activity` with `since_hours=168` for the week's finished,
blocked and failed work; `read_board` for what is open; `memory_search` over
this week's daily notes; `list_lessons` for what he read; `list_jobs` for
leads that moved. If a tool fails, say so in the review; never fill the gap
from memory.

Five sections, in this order:

1. **What happened**: the week's real outputs, one line each, with paths.
2. **What he learned**: the concepts from lessons he marked read, as he would
   say them.
3. **Open loops**: decisions waiting on him (from `memory/decisions.md`) and
   work that stalled.
4. **One idea worth writing about**: a single concrete idea with the note it
   came from.
5. **Next week's one focus**.

If his own account numbers came in this week, add one line on what
performed, with the numbers. If not, say "no numbers this week".
